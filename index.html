Stripe · Developer Infrastructure

Internal Search Infrastructure

2026

Built evaluation and retrieval infrastructure for an internal search engine used by 99% of Stripe employees.

+40%Precision@K
4×Faster evaluations
20–50%Lower search latency
5K+Weekly users

Problem

The team needed a repeatable way to measure and improve search quality while keeping retrieval fast across hundreds of thousands of internal documents.

What I built

Created an end-to-end Ruby and Braintrust evaluation framework, parallelized LLM calls with asynchronous gRPC, improved retrieval through query expansion, batching, and deduplication, and optimized GraphQL queries with indexed pagination and projections.
